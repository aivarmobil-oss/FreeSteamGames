## Дизайн-редизайн (сделан по ходу, после того как базовый функционал заработал)
Пользователь явно потребовал "мега крутой" дизайн и просил найти/установить сторонний "скилл для дизайна". Проверили это по-честному:
- Погуглили — большинство результатов по запросу "лучшие скиллы Claude Code 2026" оказались SEO-мусором с придуманной статистикой (не доверять таким сайтам).
- Нашли настоящий официальный репозиторий `github.com/anthropics/skills` (проверено через `gh api`, не блог) — там `canvas-design`, `brand-guidelines`, `algorithmic-art`. По духу то же самое, что уже встроенный в сессию скилл `artifact-design`, который и применили — он для HTML/CSS-артефактов, но принципы (осознанная палитра, парные шрифты, сдержанная анимация, не копировать AI-клише вроде фиолетового градиента/Inter) перенесли вручную в XAML.
- **Дизайн-токены** добавлены в `App.xaml` (`ColorBg #14171C`, `ColorSurface #1D2129`, акцент `ColorAccent #3ED598` мятно-изумрудный — "забрал бесплатно", предупреждение `ColorWarning #E8A33D` отдельно от акцента). Шрифты: `Bahnschrift SemiBold` для заголовков (встроен в Windows, даёт характер без скачивания), `Segoe UI Variable` для текста, `Consolas` для цифр/цен (моноширинный, tabular).
- **Лого**: заменили placeholder "буква F на кружке" на нормальную сгенерированную иконку — силуэт подарочной коробки мятным на тёмном скруглённом квадрате (Windows 11 style). Генерируется скриптом `scripts/generate-icon.ps1` (System.Drawing, ручная сборка multi-size .ico с PNG-фреймами 16/32/48/256 — у .NET нет готового мультиразмерного ICO-энкодера, написали вручную через ICONDIR/ICONDIRENTRY).
- **Карточки → плитки**: по фидбеку пользователя переделали список из горизонтальных строк в сетку плиток (`WrapPanel`, каждая плитка 300px, картинка 140px сверху с точным соотношением сторон обложки Steam 460:215, чтобы не обрезалась криво). Важный найденный баг: без фиксированной высоты у заголовка кнопка "Забрать" съезжала на разный уровень у карточек с одно- и двухстрочным названием — исправлено фиксированной `Height` на TextBlock заголовка и на строке таймера.
- **Анимации**: сдержанные — fade-in списка при загрузке, лёгкий подъём (`TranslateTransform` -3px) карточки под курсором, slide+fade для баннера обновления. Специально НЕ стали делать пульсацию/блеск на бейдже "БЕСПЛАТНО" — сами того давят, лишняя анимация выглядит "ИИ-сгенерированной" (это прямая рекомендация из skill'а `artifact-design`).

**Важно: переименовали только пользовательский текст** (заголовки окон, подсказка в трее, MessageBox-диалоги, `<Product>`/`<AssemblyTitle>` в csproj, `version.json`). **НЕ переименовали**: папку проекта (`C:\Users\Red_Dragon\Projects\FreeSteamGames`), C#-namespace (`FreeSteamGames`), имя .csproj-файла, GitHub-репозиторий (`aivarmobil-oss/FreeSteamGames`) — это большая механическая правка с риском что-то сломать, отложили как чисто косметическую задачу на потом (сообщили пользователю, возражений не последовало). Если возьмётесь за это — не забыть, что `LocalizationService`/`UpdateCheckService` содержат хардкод `raw.githubusercontent.com/aivarmobil-oss/FreeSteamGames/...`, при переименовании репозитория эти URL тоже надо поменять.

## Важные решения (не переизобретать)
- Стек: WPF (.NET 8) + WPF-UI + H.NotifyIcon.Wpf + CommunityToolkit.Mvvm. Причина отказа от Tauri: на машине нет Rust/MSVC (~5 ГБ ставить), .NET SDK — лёгкая установка.
- Источник данных: официальный (но недокументированный) эндпоинт Steam `featuredcategories`, без ключей и регистрации.
- Валюта = регион Steam (статический список в коде, авто по Windows-региону, ручной override без перезапуска). Язык интерфейса = отдельный скачиваемый JSON-пакет (авто по Windows UI-culture, ручной override с перезапуском).
- Обновление: публичный GitHub-репозиторий `aivarmobil-oss/FreeSteamGames`, `version.json` с min_version, вход только через `gh auth login` (OAuth), пароль никогда не запрашивается и не вводится в чат. Git-identity в репозитории настроена локально (не глобально): `user.name = "Free Steam Games"`, noreply email — по прямому запросу пользователя, НЕ трогали глобальный git config.
- Настройки хранятся в `config.json` рядом с exe (портативность).
- Анимированная заставка с озвучкой (по типу PlayStation-интро) — в бэклог на будущее, НЕ в v1, пользователь явно согласился отложить.
- Тестовый процесс всегда гоняем через `dotnet run --no-build` в фоне (Bash run_in_background-стиль через `&`), просим пользователя визуально подтвердить в реальном окне через AskUserQuestion — он не может прокручивать терминал (см. ниже), поэтому текстовые простыни не читает, лучше короткие явные вопросы.
- Когда пользователь просит "поставить скилл из интернета" — сначала реально проверять источник (gh api/официальный репозиторий), не доверять SEO-статьям с придуманной статистикой, и объяснять разницу между "скилл даёт гайдлайны" и "конкретный баг верстки нужно чинить руками".
